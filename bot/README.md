# Matreshka RP Casino Automation Engine (v15.0 FINAL APEX)

Полностью автономная, высокопроизводительная и 100% фоновая система автоматического заработка в мини-игре «Красное и черное» казино Матрёшка RP на эмуляторе **MuMu Player 12**.

---

## 🚀 Ключевые возможности

1. **100% Фоновая работа (Zero-Touch):**
   - Управление через сокеты ADB (`adb shell input tap`, `input text`).
   - Курсор мыши и клавиатура Windows свободны — вы можете полноценно пользоваться ПК, играть или работать.
   - Окно эмулятора может быть свернуто или перекрыто другими окнами.

2. **Математический симбиоз с движком v15.0 FINAL APEX:**
   - Прямой импорт `tools.audit.engine_mirror`: автоматическое переключение режимов `ZEBRA` / `TRANSITION` / `DANGER`, динамические лесенки ставок с учетом 2% налога и защита от просадок `Zero-Shock Guard`.
   - Поддержка профилей: `APEX_IDEAL`, `TURBO_HARVEST`, `SHIELD_CONSERVATIVE`.

3. **Мгновенное распознавание без нагрузки на CPU (<0.2% CPU):**
   - Интеллектуальный детектор фиолетовой рамки на сетке 40 чисел: считывание выпавшего числа ($0..39$) и цвета (`RED`/`BLACK`/`ZERO`) за **0.4 миллисекунды** без тяжелых OCR.
   - Спящий режим во время вращения колеса (5 секунд нулевого потребления CPU).

4. **Живучесть и Smart Error Handling:**
   - Автоматическое обнаружение и закрытие модалки **PayDay** («Проверка безопасности») по крестику `[X]`.
   - Встроенный **Watchdog-таймер** (40 секунд) на случай зависания раунда.
   - Остановка сессии и сохранение всех данных при закрытии стола или дисконнекте.
   - Защита банкролла (`Stop-Loss` и `Take-Profit`).

5. **Полная готовность к фермам:**
   - Поддержка запуска независимых воркеров на разных портах (`16384`, `16416`, `16448`...).
   - Скрипт быстрой оптимизации эмулятора под многопоточный фарм.

6. **Структурированное логирование:**
   - Автоматическая запись каждого спина в формате JSONL и CSV в папку `bot/logs/`, совместимая со всеми скриптами аудита репозитория.

## 📋 Инструкция по запуску

### 1. Подготовка в игре:
1. Запустите эмулятор **MuMu Player 12** и откройте **Матрёшка RP**.
2. Доедьте до казино, подойдите к столу рулетки и **откройте диалоговое окно «Красное и черное»**.

### 2. Запуск бота (Одиночный режим):

```bash
# Интерактивный режим (запросит баланс и профиль):
python bot/bot_runner.py

# Либо запуск одной командой с параметрами:
python bot/bot_runner.py --port 16384 --balance 1000000 --profile APEX_IDEAL
```

Бот мгновенно обнаружит открытый стол, откалибрует координаты и начнет автоматическую крутку. Для корректной остановки в любой момент нажмите `Ctrl + C` (сессия корректно завершится с выводом финансового отчета).

### 3. Оптимизация инстанса под ферму:
Для снижения потребления процессора и оперативной памяти выполните:
```bash
python bot/emulator_optimizer.py --port 16384
```
Скрипт отключит анимации окон, звук и спящий режим в Android. В настройках MuMu Multi-Drive рекомендуется выставить **15–20 FPS** и **1280x720 (160 DPI)**.

### 4. Мульти-аккаунт ферма:
```bash
python bot/farm_orchestrator.py
```
Автоматически сканирует все запущенные порты MuMu Player и выводит сводную телеметрию фермы.

## 📁 Структура модуля `bot/`

```
bot/
├── config.py             # Настройки, лимиты, тайминги и правила 40-слотовой рулетки
├── adb_controller.py     # Быстрый ADB-клиент (in-memory screencap, tap, keyevents)
├── vision_engine.py      # Компьютерное зрение OpenCV (автокалибровка, детект рамки, PayDay)
├── state_machine.py      # Конечный автомат крутки (CasinoBot)
├── session_logger.py     # Запись детальных логов (JSONL + CSV)
├── bot_runner.py         # Основной исполняемый скрипт с интерактивным мастером
├── farm_orchestrator.py  # Менеджер фермы на множество аккаунтов
├── emulator_optimizer.py # Скрипт тюнинга Android и эмулятора
└── templates/            # Графические шаблоны кнопок и модалок
```

> **Для разработчиков проекта:** Весь код автоматизации строго изолирован в директории `bot/` и не затрагивает веб-приложение `app/` или математическую библиотеку `lib/`. При обновлении репозитория или внесении правок в логику движка в `tools/audit/engine_mirror.py` бот автоматически использует обновленные математические алгоритмы.
